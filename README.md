# My Workout Tracker

12-week beginner workout program tracker.

## Setup

```bash
npm install
npm start
```

## Deploy to GitHub Pages

1. Update `homepage` in `package.json` to your GitHub Pages URL:
   `"homepage": "https://YOUR-USERNAME.github.io/workout-app"`

2. Run:
```bash
npm run deploy
```

This builds the app and pushes it to the `gh-pages` branch automatically.
